# EdgeIris

Translates tabular data from Microsoft Excel to comma-separated value files for use in data import scripts.

EdgeIris is built to be simple and practical, focusing on doing one thing well.

**Why EdgeIris?**

- Translates tabular data from Microsoft
- Excel to comma-separated value files
- for use in data import

## Key Features

- Translates tabular data from Microsoft
- Excel to comma-separated value files
- for use in data import

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/EdgeIris.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
